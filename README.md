## What is in this repository?

The repository currently contains six Python programs:

| File | Purpose | Input | Dependencies |
|---|---|---|---|
| `factorial.py` | Calculates the factorial of a non-negative integer | User input | Python standard library only |
| `fibonacci.py` | Prints the first 8 Fibonacci terms | None | Python standard library only |
| `structure.py` | Demonstrates a class while calculating a factorial | None | Python standard library only |
| `prime.py` | Checks whether an integer is prime | User input | Python standard library only |
| `palindrome.py` | Checks whether text is a palindrome | User input | Python standard library only |
| `calculator.py` | Performs a basic arithmetic operation | User input | Python standard library only |
| `cw_ses4_25bcon1288_py.py` | Contains a Hello World example, factorial calculation, and a student-data function | User input for the relevant sections | Python standard library only |

## Requirements

No third-party packages are required for the programs currently documented here. They use Python's standard functionality.

Recommended Python version: Python 3.

## How to run

From the repository directory:

```bash
python factorial.py
python fibonacci.py
python structure.py
python prime.py
python palindrome.py
python calculator.py
```

`factorial.py` asks for a non-negative integer. The other scripts use values defined in the files or prompt for their own required inputs.
